question: 'Who owns the code and the data?'
answer: 'You own both the code and the data. The code lives in your repositories from the first commit, under your licence and your review rules. The same principle applies to your data: nothing about the engagement moves ownership of the code or the data to me or to a vendor. What can change hands is access, temporarily and by agreement, for the work that needs it.'
