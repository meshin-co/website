# The order the resources are published, and what each one physically is

Decided 2026-11-10 from `investigation/10-what-exists-for-the-seven-resources.md` and the analytical round
whose answer is preserved in that record's own reasoning. Locked rows L70 to L75 carry the decisions; this
file carries the sequence and the contents, because a locked row states what was decided and not what to
build.

## The rule that sets the order

**An artefact goes ahead of another when a program already installed in other people's machines writes the
file its check reads.** Not the measured search volume, and not the date a legal duty binds.

Both of the criteria this rule replaced were tried and failed on inspection:

- **Search volume.** The site already serves every phrase Bing prices for its subjects and ranks at positions
  47 to 100. `shadow ai` carries 1,760 exact impressions over 24 weeks and the page that serves it has never
  carried a single Google impression. Volume names a door; it does not say the door opens.
- **The date a duty binds.** It ranked the Article 26 pack second while the plan shipped an Article 26
  artefact first, so it never bound anything. It also applies an EU statutory calendar to demand priced in the
  United States, where an engineer merging a pull request carries no such duty on any date.

## What the first repository contains

**Name: `evals-baseline`.** Decided by the owner on 2026-11-11 over `eval-regression-gate` and over keeping
`agent-evals-ci-starter`. It names the missing thing rather than the kit, it is short enough to be typed from
memory, and it survives the tool it reads being replaced. The site entry keeps its own slug; the repository
and the package do not inherit it.

**Three surfaces, one source.** The owner chose all three on 2026-11-11: an npm package under the scope
`@meshin`, which is his own npm username, as the thing a download counter can count; a GitHub Action wrapping
it, because one line in a workflow is the lowest entry cost there is; and a dependency-free file anyone can
copy, for a consumer whose policy forbids both. The package is the source and the other two are generated
from it, so the three cannot disagree. The Action is a liability as well as a convenience, so it ships an immutable commit and a moving `v1` tag with
the README naming the commit first. The owner chose the tag on 2026-11-11 against the evidence, which L78
records: a mutable major tag from a one-person publisher is code execution inside a buyer's CI under a name
its author can rewrite, and the companies that hire the practice are the ones whose policy refuses it. What
he takes on with it is a standing promise never to break `v1`.

**It reads two formats at launch: promptfoo and DeepEval.** Together about 6.7 million installs a month.
Inventing a neutral format instead was rejected for the same reason the governance kit went second: a format
nobody writes has a corpus of zero files, and the whole ordering rule is that the consumer must already exist.
A neutral shape may be declared later, once two real ones have been read in anger and their differences are
known rather than guessed.

**Both a specification and an implementation.** The versioned specification lives at a meshin.co address and
defines what a regression in an agent evaluation is; the repository is its reference implementation. This is
the shape SemVer has, and it is the only shape in the studied corpus that produced both installs and
citations. The specification is the part that is cited; the implementation is the part that is installed.

Four comparison rules:

1. A metric the baseline names and the current run lacks fails.
2. A value below the baseline, beyond a stated numeric tolerance, fails.
3. Metrics present only on the current run are ignored.
4. Unequal sample counts fail.

`site/scripts/catalog-drift.mjs` is the shape to copy, not the implementation. It is 28 lines; it walks the
committed side only, so rule 3 falls out of its structure, and it reports a committed entry with no observed
counterpart, which is rule 1 in a different subject. What it compares is page descriptions as strings. Rule
2 needs a numeric comparison with a tolerance and rule 4 needs a sample count, and neither exists anywhere
in this repository. The honest claim is therefore that the finding-list shape and one rule have an analogue,
and the comparison itself is new work.

The red-build fixture is two committed JSON files, so a stranger reproduces the refusal in a fork within the
hour and needs no provider key. A key is needed only to regenerate a baseline, never to watch the gate
refuse.

Three properties are not negotiable, because each one was argued against and survived:

- **The strict stop is opt-in and the default is a printed, dated finding.** Removing the sanctioned bypass
  does not remove the bypass; it removes the only visibility into who bypassed. A line disabling the step
  costs one line and says nothing to anyone.
- **Nothing exits non-zero on a clock.** A stranger's build turning red with no diff, on a day they are
  shipping something unrelated, is the fastest route to a deleted step.
- **A green must be expensive to fake.** Every check binds to a referent inside the consumer's own
  repository. The pattern to copy is `digestFor` in `site/scripts/dispositions.mjs`, which hashes the
  target's own text so a row goes stale when the text moves.

## What the second repository contains

The procurement answer a register can produce, not a pack of documents. The primary command prints the
answer the engineer is already under pressure to deliver and refuses only to print a claim it cannot verify;
the vacancy is printed, visible, rather than the export being withheld. The payload carries identifiers only
— clause numbers, control ids, question ids — never upstream clause text, because ISO/IEC 42001 grants no
derivative rights, the OWASP edition is ShareAlike, and the CSA and SCF sets forbid derivatives.

It ships a refusal list in `CONTRIBUTING.md` naming ISO Annex A text, the CSA AI-CAIQ, the SCF and the CNIL
sheets as permanently out of scope, plus an artefact count that will not grow. That list is the only defence
against being asked, politely and repeatedly, to build the thing that cannot be redistributed.

## What was decided about announcing

Nothing is announced. The owner chose on 2026-11-10 that the resources are found rather than published at an
audience.

The cost of that choice is recorded here so it is not mistaken for an oversight. The same channel has already
run for nine weeks from the first resource publication on 2026-09-08 and produced zero clicks, zero article
impressions, and `status: absent` on 120 of 120 AI-engine prompts with retrieval confirmed on 52 of them. No
artefact in the studied corpus became canonical without one borrowed audience on one day. The sequence above
is therefore built so that the distribution that remains is mechanical rather than social: a redistribution-
permitting licence, and an artefact a program consumes.

## What is not decided here

Whether HECVAT question text may be republished inside a differently-licensed artefact aimed at commercial
companies. "No cost and without a further license" is a distribution statement rather than a grant, and the
answer decides what the second repository physically contains. It is read directly from EDUCAUSE before that
repository is written, never from a secondary summary.
